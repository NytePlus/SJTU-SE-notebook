## Obsidian

仓库本身可以直接作为 Obsidian Vault 使用：

```bash
git clone <repository-url>
```

然后在 Obsidian 中选择 **Open folder as vault**，打开仓库根目录即可。

`.obsidian/` 中保存了当前 Vault 的部分配置。
